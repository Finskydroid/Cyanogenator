# Cyanogenator
<img width="754" height="421" alt="image" src="https://github.com/user-attachments/assets/8df053c7-f059-414a-a110-b58d73e7682b" />

Transform your phone into the classic, nostalgic CyanogenMod experience; I’ve put together this "instruction manual" based on my own experience and knowledge regarding the topics and tools covered.

This guide is based on a specific version—though not one so obscure that you cannot easily replicate the setup. The most stable and tested version for this project is **LineageOS 19.1 GSI bvN (based on testing with the Samsung A31 4G, Brazilian variant)**, which can be found in Andy Yan's SourceForge repository. While most people familiar with the Android world know this source, for those new to the scene, I will always provide the links at the end of the text.

Sourceforge repository mentioned: https://sourceforge.net/projects/andyyan-gsi/
